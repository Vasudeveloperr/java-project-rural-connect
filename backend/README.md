# RuralConnect Java Backend

Java Servlet backend for the RuralConnect college project.

## Stack
- Java 17+
- Apache Tomcat 11.0.26
- Jakarta Servlet 6.1
- Maven
- MySQL 8+
- JDBC

## Main endpoint
GET `/api/products`

More endpoints (login, products, orders, auctions and bids) will be added in the next integration stage.
